# 使用说明

## 1. 基本用法

打开：

```text
skill/专业预测可复制版.txt
```

复制整段到 AI 工具里，然后输入你要分析的比赛。

## 2. 推荐输入模板

```text
请用专业足球数据预测 Skill 分析这场比赛：

比赛：
比赛时间：
比赛阶段：
场地：
主客/中立场：
可用数据：
我重点关注：
输出语言：
```

示例：

```text
请用专业足球数据预测 Skill 分析这场比赛：

比赛：法国 vs 阿根廷
比赛时间：2026-06-20 20:00
比赛阶段：淘汰赛
场地：待确认
主客/中立场：中立场
可用数据：请优先联网核对最新赛程、近况、伤停、预计首发、xG/xGA、进失球、排名和休息天数。
我重点关注：胜平负概率、比分分布、关键战术对位、高威胁回合、进球链路拆解。
输出语言：中文，专业术语充分。
```

## 3. 数据不足时怎么用

如果不能联网，建议用户补充：

- 双方近 5 到 10 场比分
- 预计首发和阵型
- 伤停与停赛
- xG / xGA 或射门数据
- 积分榜或晋级条件
- 休息天数和旅行情况

没有这些数据时，Skill 必须在“不确定性因素”里说明哪些判断是低置信估计。

## 4. 输出目标

输出不是赛后复盘，也不是平台文案。目标是生成一份赛前专业预测报告，重点回答：

- 为什么这个概率分布合理？
- 哪些战术对位最可能产生机会？
- 进球可能怎样一步一步出现？
- 哪些变量会让预测失效？
