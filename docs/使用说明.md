# 使用说明

## 1. 基本用法

打开：

```text
skill/专业预测可复制版.txt
```

复制整段到 AI 工具里，然后输入你要分析的比赛。

## 2. 推荐输入模板

```text
请用专业足球数据预测 Skill 分析这场比赛：

比赛：
比赛时间：
比赛阶段：
场地：
主客/中立场：
可用数据：
是否允许联网核验：
是否有赔率或 xG 数据：
我重点关注：
输出语言：
```

示例：

```text
请用专业足球数据预测 Skill 分析这场比赛：

比赛：法国 vs 阿根廷
比赛时间：2026-06-20 20:00
比赛阶段：淘汰赛
场地：待确认
主客/中立场：中立场
可用数据：请优先联网核对最新赛程、近况、伤停、预计首发、xG/xGA、进失球、Elo/排名、赔率和休息天数。
是否允许联网核验：允许
是否有赔率或 xG 数据：没有，请公开来源核验
我重点关注：期望进球、胜平负概率、比分分布、关键战术对位、高威胁回合、进球链路拆解。
输出语言：中文，专业术语充分。
```

## 3. 可复现概率底座

如果已经有双方 xG、Elo、主客场和赔率输入，可以先填 `templates/match_input_template.json`，再运行：

```bash
python3 scripts/football_prediction_sim.py templates/match_input_template.json
```

脚本会输出：

- 两队期望进球
- 原始 Poisson / Dixon-Coles 风格胜平负概率
- 可选市场校准后的概率
- 最可能比分

脚本结果是概率底座。最终报告仍需要核验数据、解释假设和加入战术推演。

## 4. 数据不足时怎么用

如果不能联网，建议用户补充：

- 双方近 5 到 10 场比分
- 预计首发和阵型
- 伤停与停赛
- xG / xGA 或射门数据
- Elo / FIFA 排名 / 联赛强度
- 赔率或市场隐含概率
- 积分榜或晋级条件
- 休息天数和旅行情况

没有这些数据时，Skill 必须在“模型假设与数据质量”和“不确定性因素”里说明哪些判断是低置信估计。

## 5. 输出目标

输出不是赛后复盘，也不是平台文案。目标是生成一份赛前专业预测报告，重点回答：

- 数据是否可靠、是否新鲜？
- 期望进球如何得到？
- 为什么这个概率分布合理？
- 模型与市场是否有明显分歧？
- 哪些战术对位最可能产生机会？
- 进球可能怎样一步一步出现？
- 哪些变量会让预测失效？

## 6. 赛后回测

赛前把预测写入：

```text
data/historical_predictions_template.csv
```

赛后补上实际比分和赛果，然后运行：

```bash
python3 scripts/backtest_predictions.py data/historical_predictions_template.csv
python3 scripts/calibrate_probabilities.py data/historical_predictions_template.csv
```

第一个脚本看预测表现，第二个脚本给概率校准 temperature。

## 7. 更专业的数据分析

需要深入数据分析时，参考：

```text
docs/专业数据分析参考.md
```

优先增强顺序：

1. shot-level xG
2. VAEP / xT 球员动作价值
3. 定位球攻防 profile
4. Dixon-Coles 低比分拟合
5. mplsoccer 可视化
