# 专业数据分析参考

这个文档用于把单场预测从“概率报告”提升到“专业足球分析工作流”。只有在需要更深数据分析时读取。

## 1. 事件数据与开放数据

### StatsBomb Open Data

用途：

- 射门、传球、压迫、抢断、定位球、门将动作等事件级分析。
- 构建 xG、传球链路、进攻三区推进、定位球套路样本。
- 验证高威胁回合是否符合真实比赛事件分布。

适合加入的字段：

- shot location
- shot body part
- assist type
- pressure
- play pattern
- set-piece type
- possession chain

## 2. xG 与射门质量

### soccer_xg

用途：

- 训练或参考自建 xG 模型。
- 把 proxy_xG 从“射门数量加权”升级到“射门位置、角度、身体部位、助攻方式、压力”的模型。

增强方向：

```text
shot_xg = f(distance, angle, body_part, assist_type, pressure, game_state)
team_xg = sum(shot_xg over recent matches)
```

如果没有事件级数据，继续使用当前 proxy_xG 梯子。

仓库内提供透明代理脚本：

```bash
python3 scripts/shot_xg_proxy.py shots.csv
```

CSV 字段：

```text
team,distance,angle,bodyPart,assistType,underPressure,isBigChance
```

这不是训练好的 xG 模型，只适合在没有 direct xG 但有射门事件时作为 shot-level proxy。

## 3. 动作价值与球员贡献

### socceraction / VAEP / SPADL

用途：

- 给每个动作估算对进球概率和失球概率的影响。
- 更真实地评价球员贡献，而不是只看进球助攻。
- 判断某球员缺阵到底影响推进、创造、反抢还是防守稳定。

可映射到 skill 字段：

| 分析结果 | skill 字段 |
|---|---|
| 关键传球/推进价值高 | keyPlayerAttackImpact |
| 防守动作价值高 | keyPlayerDefenseImpact |
| 高价值替补 | benchImpact |
| 中场控场动作价值高 | possessionControl / tacticalCoherence |
| 反抢动作价值高 | pressingIntensity |

## 4. 概率模型与比分分布

### penaltyblog

用途：

- Poisson、Bivariate Poisson、Dixon-Coles、贝叶斯足球模型。
- 赔率隐含概率、市场校准、fair odds。

适合增强：

- 替代或校验当前 `football_prediction_sim.py` 的比分矩阵。
- 用历史数据拟合 Dixon-Coles rho。
- 用赔率做 market sanity check。

### goalmodel

用途：

- Dixon-Coles 低比分修正。
- 预测评分：Brier、log score、ranked probability score。

适合增强：

- 0-0、1-0、1-1、0-1 的概率校准。
- 回测时增加 ranked probability score。

## 5. 数据标准化

### kloppy

用途：

- 统一 StatsBomb、Wyscout、Opta、Metrica 等事件/追踪数据格式。
- 避免每个数据源都写一套解析器。

适合增强：

- 新增 `scripts/normalize_events.py` 时参考。
- 把事件数据转换为统一 shot/pass/possession schema。

## 6. 可视化

### mplsoccer

用途：

- 射门图、传球网络、阵型图、热区、雷达图。
- 给预测报告生成可视化证据。

适合输出：

- shot map
- pass network
- set-piece map
- player contribution radar
- field tilt chart

## 7. 建议增强顺序

1. 新增 shot-level xG：从 proxy_xG 升级到 shot_xG。
2. 新增 player value：用 VAEP/xT 思路量化关键球员影响。
3. 新增 set-piece profile：把定位球攻防从手动调整升级为样本统计。
4. 新增 Dixon-Coles fitting：用历史数据拟合低比分相关参数。
5. 新增 visualization：用 mplsoccer 输出图表。

## 8. 使用原则

- 没有实际运行项目或脚本时，只写“方法参考”，不要写“已使用该模型计算”。
- 事件数据和 xG 模型必须标注来源、样本窗口和数据版本。
- 专业指标必须最终映射回预测变量：lambda、概率、比分、战术事件流、关键球员影响或不确定性。
