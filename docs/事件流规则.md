# 事件流规则

## 1. 高威胁回合结构

每个高威胁回合必须包含：

- 时间段
- 进攻方
- 进攻类型
- 威胁等级
- 发起
- 推进
- 关键动作
- 防守反应
- 终结
- 成立原因

格式：

```text
第 18-22 分钟｜主队｜中路渗透｜威胁等级 72/100
发起：
推进：
关键动作：
防守反应：
终结：
成立原因：
```

## 2. 进球链路结构

进球回合必须额外包含：

```text
进球方式：
预期进球质量：
防守失误点：
```

完整链路要能解释：

- 球权从哪里来
- 进攻如何推进到危险区域
- 哪个动作制造防线错位
- 防守方哪里没有处理好
- 射门为什么能形成进球

## 3. 推荐进攻模板

### 边路传中

适合：边路速度强、禁区抢点强、对手边后卫回防慢。

关键词：外侧套上、边路 2v1、禁区占位、后点包抄。

### 倒三角回传

适合：边锋或边后卫能压到底线，中路有后插上球员。

关键词：底线突破、禁区回撤点、Zone 14、后腰漏人。

### 肋部直塞

适合：前腰或 8 号位传球能力强，前锋有斜插能力。

关键词：半空间、第三人跑动、中卫与边后卫之间通道。

### 高位逼抢二次进攻

适合：压迫强、反压迫快、对手后场出球质量不稳。

关键词：压迫触发点、二点球、就地反抢、防线未重组。

### 低位反击

适合：防守站位紧凑、转换速度快、对手 rest-defense 薄弱。

关键词：第一脚向前、身后空间、弱侧冲刺、少打多转多打少。

### 弱侧转移

适合：控球方能吸引一侧压迫，弱侧边锋或边后卫有空间。

关键词：横向转移、防线横移、远端接应、传中或内切。

### 定位球二点

适合：制空点强、对手二点保护差。

关键词：前点蹭、后点压制、禁区弧顶二点、混战射门。

## 4. 真实性约束

- 高威胁回合不等于进球。
- 强队也会有低质量射门和被反击。
- 领先后可能降低压迫强度。
- 落后后可能提高阵线，导致身后空间增大。
- 体能下降后，回追速度和禁区前沿保护通常变差。

## 5. 与模型一致

- 高威胁回合数量要跟 `lambda` 匹配。总期望进球低于 2.0 时，不应写成开放对攻。
- 比分分布最高项如果是 1-1 或 1-0，事件流应包含更多未转化机会和低质量终结。
- 高 transitionSpeed 对弱 rest-defense 时，优先写反击、身后球、弱侧冲刺。
- 高 pressingIntensity 对弱后场出球时，优先写前场抢断、反压迫、二次进攻。
- 高 setPieceThreat 对弱制空或二点保护时，优先写定位球和混战二点。
- 领先后的回合要体现风险管理；落后的回合要体现阵线提高和身后空间。
